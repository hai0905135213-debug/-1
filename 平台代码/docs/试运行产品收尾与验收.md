# 试运行产品收尾与验收

更新：2026-10-21。范围是本地业务功能，不包括部署、微信编译、真实微信登录或真机发布。

## 本轮交付

- 首次使用填写昵称、校区与可选偏好，明确确认当前版本的服务和隐私说明；未确认不能发布或报名。体验白名单仍单独审批，不冒充学籍认证。
- 登录、首次引导后回到原饭局；网页可复制饭局邀请链接，小程序源码提供饭局分享入口。
- 原网页布局保留。小程序动态页改为真实帖子，评价统一从已完成饭局选择真实队友，不再手填用户编号。
- 未读通知角标与前台轮询；没有关联饭局的服务通知跳转反馈中心。换账号时丢弃旧账号的角标请求结果。
- 用户反馈、餐厅纠错与处理结果申诉，管理员回复，用户可看自己的进度与举报结果。
- 管理员可预览并隐藏饭局、帖子、留言，必须填写原因，保留日志并通知相关用户。隐藏招募饭局会取消饭局并关闭待审批申请；恢复展示不会自动恢复招募或关联帖子。
- 管理员核验分店地址，记录来源及公开核验说明。修正地址后停用旧坐标和直线距离，等待地图补全；已发布饭局的地点快照不变。不能以新地址配旧距离。
- 用户查看本人资料、课程及数据统计；清空课表同时删除课程与时间设置。注销前必须处理未结束饭局；注销删除当前个人资料等数据、匿名化历史组织内容、撤销全部设备会话。历史成员关系仅保留匿名关联。
- 停用账号撤销所有旧会话；最后一名有效管理员不能被停用或注销。

## 本地运行

在项目根目录下分别启动：

```sh
cd 平台代码/backend
ENABLE_DEV_LOGIN=true node src/server.js
```

```sh
cd 平台代码/frontend
PORT=5174 npm run preview:web
```

浏览器打开 `http://127.0.0.1:5174/`。本机需可用的 Node.js 22 和已安装依赖。开发登录只用于本地测试，不可对外作为真实身份登录。

Windows 使用环境文件更方便：复制 backend/.env.example 为 .env，明确设 ENABLE_DEV_LOGIN=true，然后 `node --env-file=.env src/server.js`。不要把 .env 或业务数据库提交到公开仓库。

## 管理员与外部配置

1. 使用自己的测试账号登录，从本地业务库核对用户编号；运营指定 `ADMIN_USER_IDS`，重启后赋予权限。客户端不能自助成为管理员，代码不擅自给现有账号提权。
2. 管理页批准参与试运行用户的体验资格；首次引导与白名单是两个独立条件。
3. 对外试用前填写 `PUBLIC_OPERATOR_NAME` 和 `PUBLIC_SUPPORT_CONTACT`，展示真实运营主体与联系方式。默认说明明确表示尚待配置，不生成假联系方式。
4. 运营仍须决定备份保留期限、访问权限和按期清理办法。注销会清理当前业务数据，**不会即时擦除历史备份**。迁移前自动生成备份，勿放在公开目录。现有隐私说明是功能行为披露，不构成已完成全部法律或平台合规审核的保证。
5. 真实微信 AppID/AppSecret、接口域名和设备验证、原网页设计向小程序的完整移植，留待后续专门处理。AppSecret 只能在后端。

## 数据与代码位置

- `backend/src/product.js`：版本5迁移、同意记录、反馈、处置、纠错与账号数据接口。
- `backend/src/teams.js`：会话、白名单、审批与饭局状态；`discovery.js` 保留规则推荐与优惠管理。
- `frontend/preview-static/product.js`：原网页收尾接入；没有替换原首页布局。
- `frontend/pages/onboarding/`、`support/`：小程序源码中的引导与服务中心。
- `frontend/services/session.js`、`notification-badge.js`：站内登录返回及未读角标。
- 纠错记录写业务库 `restaurant_adjustments`；独立餐厅仓保持只读。版本5迁移前备份为业务数据目录下 `backups/before-product-*.db`。

## 验证方式与边界

2026-10-21 实测：后端26项通过，原网页33个检查步骤通过（包含两名用户分别首次引导），20个Vue页面语法通过。没有执行微信编译。

后端：在 backend 目录运行 `npm test`。网页：根目录运行 `node scripts/verify_original_ui.mjs`（需要 Playwright 和 Chrome；可用 CHROME_EXECUTABLE 指定路径）。两者使用临时业务库，餐厅仓只读，不向日常业务库塞入验收账号、留言或优惠。

网页验收覆盖原样式首屏、搜索、组合筛选、分店快照、白名单、申请审批、满员、留言权限、撤回、退出重开、拒绝、取消、完成互评、PDF课表确认、规则推荐、优惠、首次引导、邀请恢复、反馈回复、隐藏内容、清空课表和注销。

这属于本地自动化验收。微信真机、跨设备访问、上线容量、备份恢复演练和正式隐私配置尚未验收，不以模拟结果冒充完成。未接在线支付、真实核销、自动派单或独立到场核验。
